## 我负责把需求做完

我从 2020 年开始自学开发。兴趣范围很散，但做事的方法很固定：先把问题讲清楚，做出可运行版本，再放进真实浏览器、桌面系统或设备里验证。

现在主要在做 Web 图形、跨平台桌面工具和 ESP32 小设备。这里不放“精通一切”的标签，只展示已经做出来的东西。

> 喵总决定什么值得做，我负责把它做成产品。

## 精选交付

| 项目 | 解决的问题 | 技术与入口 |
| --- | --- | --- |
| [**Port Guardian**](https://github.com/soBigRice/port-guardian) | 把端口占用排查、进程定位和结束操作收进一个跨平台桌面工具。 | `Rust` / `Tauri` / [Releases](https://github.com/soBigRice/port-guardian/releases) |

| [**WiFi Calendar**](https://github.com/soBigRice/wifiCalendar) | ESP32 与墨水屏桌面日历，处理联网、天气和低功耗显示。 | `C` / `ESP32` / `E-Ink` |
| [**cesium.path**](https://www.npmjs.com/package/cesium.path) | 发布到 npm 的 Cesium 路径动画库，用于飞行轨迹和路径表现。 | `JavaScript` / `Cesium` / [Source](https://github.com/soBigRice/Cesium.path) |
