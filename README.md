## 01 / 最近在做

### [soRound OS](https://github.com/soBigRice/soRound_os) · 掌心里的小世界

<a href="https://sobigrice.github.io/soRound_os/">
  <picture>
    <source media="(prefers-color-scheme: dark)" srcset="./assets/project-soround-dark.svg" />
    <img src="./assets/project-soround-light.svg" alt="soRound OS：466 × 466 圆形 AMOLED，ESP32-S3 / ESP-IDF / LVGL。右侧为项目原生天气界面预览。" width="100%" />
  </picture>
</a>

给 **1.75 英寸圆形 AMOLED** 做一套轻量系统：表盘、天气、音频可视化、小游戏、BLE 遥控与数字孪生，还有双分区 OTA。硬件、固件与 Web 交互一起打磨。

`ESP32-S3` · `C` · `ESP-IDF` · `LVGL` · `Three.js`

**[逛项目官网 ↗](https://sobigrice.github.io/soRound_os/)** &nbsp; / &nbsp; [看源码](https://github.com/soBigRice/soRound_os) &nbsp; / &nbsp; [固件与发布记录](https://github.com/soBigRice/soRound_os/releases)

### [LynkCo-DiPlay](https://github.com/soBigRice/LynkCo-DiPlay) · 把体验带进车里

<a href="https://sobigrice.github.io/LynkCo-DiPlay/">
  <picture>
    <source media="(prefers-color-scheme: dark)" srcset="./assets/project-lynkco-dark.svg" />
    <img src="./assets/project-lynkco-light.svg" alt="LynkCo-DiPlay：面向领克 OS N 2.0 / Android 9 的 DiPlay 适配，右侧为项目连接首页，基于上游 DiPlay。" width="100%" />
  </picture>
</a>

基于 **[DiPlay](https://github.com/shihabal3amri/DiPlay)** 的领克车机 CarPlay 适配，围绕 Android 9 的连接恢复、界面与诊断做改进。

`Kotlin` · `Android 9` · `Lynk OS N 2.0` · `CarPlay`

**[了解项目 ↗](https://sobigrice.github.io/LynkCo-DiPlay/)** &nbsp; / &nbsp; [看源码](https://github.com/soBigRice/LynkCo-DiPlay) &nbsp; / &nbsp; [兼容与构建说明](https://github.com/soBigRice/LynkCo-DiPlay/blob/main/README.zh-CN.md)

<sub>独立适配，保留上游署名；有线已有实车验证，无线仍待验证。当前公开源码，完整 APK 尚未发布。具体支持范围以项目说明为准。</sub>
