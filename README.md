## 关于我

我是 **米大饭 / soBigRice**，一个偏技术博客风格的自学开发者。

除了做项目，我也习惯把开发过程里的设计思路、踩坑记录、可复用方案整理成文字。这个主页不只是项目索引，也是一份公开的技术笔记入口。

一些过去做过的作品和实验，也在整理后陆续开源。

我长期会围绕这些方向持续折腾和记录：

- `Node.js` 小服务和工具
- `WebGL / WebGPU` 视觉实验
- `Vue / TypeScript` 小作品和页面
- `ESP32 + 墨水屏` 这类带一点硬件味道的尝试

> Life is like a play, and the play is like life, a fleeting illusion. Why take it seriously?
